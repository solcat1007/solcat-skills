# Open Source Assets 开源素材收录

本目录只收录**来源与协议可验证**的开源素材。每项必须注明：原作者、原始链接、开源协议。收到 DMCA 或版权异议时按本文件溯源处理。

收录标准：作者明确以 CC0 / CC-BY / MIT 等开源协议发布，或来自 Blender 官方 demo-files（CC 协议）等公认开源渠道。**付费素材、来源不明的素材一律不收。**

## Blender

### isometric-room（`./blender/isometric-room/`）

- **作者**：sarthakm402
- **来源**：<https://github.com/sarthakm402/isometirc-room>
- **协议**：MIT License（原仓库 `LICENSE` 文件随附）
- **内容**：Blender 制作的静态等距房间场景，含 `room.blend` 源文件
- **可做什么**：自由使用、修改、再分发（保留版权声明即可）
