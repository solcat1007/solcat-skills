# 设计接单与素材资源工具箱

## 一、接单渠道对比

| 渠道 | 优势 | 劣势 | 适合谁 |
|---|---|---|---|
| 猪八戒/一品威客 | 单量大 | 团队竞争、压价、比稿，新手难存活 | 有议价经验者 |
| 花瓣美思/千图网（创作者分成） | 被动收入 | 要求持续产出高质量素材，收入与下载量强挂钩 | 有作品库积累者 |
| 淘宝设计店铺（兼职派单） | 不愁客源，周结/月结 | 店铺抽成，命题作文多 | 想稳定练手的新人 |
| 闲鱼 | 零门槛挂链接；定金可走担保交易 | 客单价低，需自己引流 | 新人第一单 |
| Q 群/豆瓣小组 | 直接触达甲方 | 广告多、狼多肉少、价格低 | 练手，别长期做 |

**新手策略**：小单练手可以，但不要长期停留在低价单——不利于能力与报价的成长。接单必收定金（30%~50%），改稿次数写进约定。

| 网站 | 特点 |
|---|---|

| Gratisography | 风格化摄影，个性强 |
| Picjumbo | 分类细：建筑、商业、食物等 |
| Life of Pix | 欧洲生活/景观，公共领域捐赠 |
| Freeimages | 有中文站，分类细致 |

| 别样网 ssyer | 国内可直连，无版权 |
| Visual Hunt | 按颜色搜图 |
| Vecteezy | 免费矢量图索引 |

## 四、免抠元素与 PSD

- 觅元素、365PSD、千图网/千库网/包图网/站长素材（国内综合站，注意部分需会员，认准授权范围）
- 用免抠元素前确认商用授权，国内站的"个人免费"通常不含商用

## 五、字体

- **求字体**：上传截图识别字体（中英日韩、书法体）
- **字体传奇 / 字体之家 / 第一字体转换器**：预览、下载、在线特效
- ⚠️ 商用项目必须确认字体的**商用授权**；中文字体侵权是设计圈最高频的赔偿纠纷。优先用免费商用字体（思源黑体/宋体、阿里巴巴普惠体、OPPO Sans 等）

## 使用建议

帮用户找素材时按「用途 → 授权要求（是否商用/是否需署名）→ 风格」三步过滤，再给链接；交付设计稿时附素材授权清单，避免客户后续纠纷。
