# 海龟汤判题示例与救场话术

## 判定示例

| 玩家提问 | 判定 | 说明 |
|---|---|---|
| "死者是被谋杀的吗" | 视汤底 | 若汤底是自杀/意外，答"否"；若与他杀无关的细节，答"无关" |
| "他是被另一个'人'杀的吗" | 是也不是 | 引号可能指非人类——先答"是也不是"，观察玩家下一步 |
| "门是开着的很重要吗" | 是 | 命中汤面伏笔，可补"这是目前最重要的线索之一" |
| "大家是不是都疯了" | 否 | 经典脑洞试探；若汤底确属变格再按汤底答 |
| "我能再听一遍汤面吗" | 规则外 | 可以重读汤面，不计时 |

## 常见卡点场景与救场话术

**场景一：玩家只在问人物关系**
> "人物关系挖得很细了，但汤底的关键藏在'时间'里——有没有人想问那天发生了什么？"

**场景二：玩家方向完全跑偏（认定超自然）**
> 不说"错了"，统一判"否"："这个方向的问题，答案都会让你失望。"玩家会自己换向。

**场景三：全场冷场**
> 主动播报三栏表："目前确认的：死者是自愿的、现场没有第二个人。已排除的：药物。还没人问过：案发地点的特殊性。"

**场景四：有人一击命中核心但队友没跟上**
> 判"是"后停顿两秒："这个'是'值多少钱？谁能顺着它把故事讲完？"

**场景五：新手问题封闭性差**
> 给模板："试着把问题改成'是不是 X'的形状——'他是不是从没离开过房间？'"

## 收尾复盘话术模板

1. "汤底是……"（完整讲述，控制在 2 分钟内）
2. 回指："其实第三个问题'他是自愿的吗'就已经摸到门口了，最后是哪个问题把门推开的？"
3. 点名全场最巧的一问，具体到人
4. 给下一题的改进建议："下次开局先问'这里有几个人'，能省掉一半弯路"

## 原创汤面质量自检清单

出题后过一遍：

- [ ] 汤面 30 秒能读完？
- [ ] 汤底唯一可解，没有第二个自洽解释？
- [ ] 反转藏在公平出现的细节里，而不是藏在"我没说"的信息里？
- [ ] 本格题不违反物理逻辑？变格题开场已声明？
- [ ] 不含现实恶性案件可对号入座的细节？
