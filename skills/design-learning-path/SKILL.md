# 设计自学路线

## 四阶段路线图

| 阶段 | 目标 | 时长参考 | 通关标志 |
|---|---|---|---|
| 1. 软件操作 | PS 工具、图层、蒙版、通道、调色面板 | 2~4 周 | 能独立抠出毛发、会用全部调色工具 |
| 2. 专项技能 | 选一个主方向深入（人像精修 / 合成 / 平面版式） | 2~3 个月 | 复刻 3 张同类商业作品，肉眼难辨 |
| 3. 作品集 | 整理 10~15 张代表作，统一风格 | 1 个月 | 有能力给自己"定位"：我是修 XX 的 |
| 4. 接单变现 | 用 design-freelance-toolbox 的渠道开始接单 | 持续 | 首个陌生客户复购 |

## 阶段一：软件操作清单

按顺序掌握，缺一不可：

1. 选区与抠图：选框 → 套索 → 钢笔 → 通道（难度递增）
2. 图层与蒙版：剪贴蒙版、图层混合模式（正片叠底/滤色/柔光三大件）
3. 调色：曲线、色阶、色相饱和度、可选颜色、色彩平衡
4. 修复工具族：污点修复、修补、图章
5. 智能对象与智能滤镜
6. 动作与批处理

自检：给一张杂乱背景的人像，10 分钟内完成"抠图 + 换背景 + 统一色调"。

## 阶段二：专项方向怎么选

| 方向 | 核心技能链 | 变现场景 |
|---|---|---|
| 人像精修 | 磨皮（高低频/中性灰）→ 液化 → 补妆 → 调色 | 影楼、电商、cos 后期 |
| 合成特效 | 溶图匹配（明度/饱和度/色温）→ 画光 → 氛围 | 海报、游戏宣传 |
| 平面版式 | 字体 → 网格 → 留白 → 印刷规范 | 品牌物料、电商详情 |

判断依据：最喜欢做哪种图？翻你手机相册里收藏过的图，出现最多的类型就是答案。

## 练习方法：临摹 → 分析 → 变体

1. **临摹**：1:1 复刻一张目标图，卡住的地方就是知识盲区
2. **分析**：把目标图拆成图层结构写出来（几层、什么模式、什么顺序）
3. **变体**：用同样的技法换素材做一张新的——能变体才算掌握

每阶段 3 张变体作业，比 30 张半成品有效。

## 常见卡点诊断

| 症状 | 病根 | 药方 |
|---|---|---|
| 修图"越修越脏" | 色彩管理没过关 | 回炉阶段一调色工具，做黑白灰观察层训练 |
| 会工具但做不出图 | 缺审美输入，不是缺技术 | 建立参考库，每天拆解 1 张优秀作品的结构 |
| 单张还行，整套不行 | 缺系统/规范意识 | 学版式网格与统一风格模板 |
| 不敢接单 | 作品集撑不起报价 | 先做 3 张免费/低价单换案例与证言 |
