# 漫展场照拍摄

## 行前准备清单

**器材**（漫展特殊性：室内、人多、光线杂）

- 机身 + 大光圈定焦（35/50/85，室内抢背景分离全靠它）
- 备用电池 ≥2、存储卡 ≥2——漫展没有"回头补拍"
- 小型补光：LED 棒或热靴闪光灯 + 柔光罩（展馆顶光是死光，必须补）
- 反光板慎用：人流大，没地方立

**功课**

- 展会平面图先存好，标记馆外自然光点位（玻璃幕墙、天桥）与馆内暗区
- 和 coser 提前对：角色、返图需求（全身/特写占比）、能接受的姿势尺度、当天联系方式
- 约定拍摄时段：开场后 1 小时人流最少，正午馆外顶光最差

## 现场机位与用光

| 场景 | 打法 |
|---|---|
| 馆内暗区 | 大光圈贴 ISO 上限；闪光灯朝天花板跳闪或加柔光罩直打，宁欠勿爆 |
| 玻璃幕墙边 | 让 coser 侧对窗，你站逆光位加补光，发丝光白拿 |
| 馆外广场 | 顺光赶时间、侧光出立体；正午顶光找树荫/建筑阴影 |
| 人多背景乱 | 压光法：对人物正确曝光、让背景欠曝 1~2 档，人群自动"暗化" |
| 动作戏（挥刀/跳跃） | 快门 ≥1/500，连拍 + 预判顶点，提前占位 |

## 与 coser 的现场配合

1. 开拍前 30 秒检查：假发乱不乱、妆面反光、道具拿法、服装标签外露——这些当场说，比后期救便宜十倍
2. 指令要具体：说"下巴收一点，眼睛看我的手"，不说"自然一点"
3. 连拍 3 张一组：中间动势、定住的两头各一张，回去好挑
4. 每换一个点位先给 coser 看两张成片，确认方向对了再深入
5. 尊重边界：所有姿势先示范再邀请，coser 说不行立刻换

## 应对人流与场务

- 三脚架在主通道基本禁用/碍事，用稳定手持或寻找墙边固定点
- 背景抢不过就让：等 30 秒人流间隙，比硬拍 100 张废片划算
- 尊重其他摄影和 coser 的排队默契：同一点位轮流拍，别长时间占机位
- 未成年人 coser 必须有监护人在场才拍摄

## 拍后交付规范

1. 24 小时内先给 **9~12 张精选小图**（带轻水印）让 coser 挑
2. 约定精修张数（通常 3~9 张）与交付期限，写清楚
3. 精修交给 cosplay-retouch 流程处理
4. 原片是否给、是否允许 coser 另找后期，开拍前就说好
5. 双方发布时互 @，标注场地与角色名
