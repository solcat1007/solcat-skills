# 剧本杀剧本创作

## 何时使用

- 从零构思一个剧本杀本
- 已有故事但缺诡计、缺线索、缺机制
- 需要检查已有剧本的时间线漏洞和逻辑硬伤
- 需要设计搜证、私聊、投票等环节

## 核心工作流

### 1. 先定类型与人数

这两项决定后面所有设计，必须先定：

| 维度 | 选项 | 影响 |
|---|---|---|
| 类型 | 本格推理 / 变格（超自然、机制）/ 情感 / 恐怖 / 欢乐 | 决定诡计是否允许超现实设定 |
| 人数 | 常见 5-8 人 | 决定角色关系和线索承载量 |
| 时长 | 3h / 4h / 5h+ | 决定幕数与线索数量 |
| 主线 | 硬核推理 / 剧情沉浸 / 机制博弈 | 决定玩家主要精力分配 |

### 2. 凶案设计（本格）

从「结果」倒推，不要从「故事」顺推。顺序是：

1. **确定死法**：死因、死亡时间、尸体发现方式、发现者
2. **确定凶手**：谁是凶手，凶手的动机与行为链
3. **反推手法**：凶手如何做到，用什么工具、什么漏洞
4. **设计遮蔽**：凶手如何制造不在场证明或转移嫌疑
5. **铺设线索**：让真相可被推导出来，且至少有 2 条独立路径指向凶手

关键原则：**凶手必须是逻辑上唯一可能的人**。如果排除法能得出多人，就是设计失败。

### 3. 角色设计

每个角色都必须有：

- **公开身份**：别人一开始就知道的信息
- **秘密**：需要玩家自己决定何时暴露
- **动机**：与凶案或死者的关系（每个人都有动机，才不显得突兀）
- **人物弧光**：在剧本结束时该有的转变或揭露

三个红线：

1. 不能有「边缘角色」——每个角色都要有能推动剧情的信息
2. 不能有「纯工具人」——只为提供线索而存在，没有自己的欲望
3. 凶手角色不能因为知情过多而无法扮演

### 4. 时间线

这是最容易出错的部分。必须用**双时间线**表格管理：

| 时间 | 客观事实（真实发生） | 各角色自述（他们所知道的/所编造的） |
|---|---|---|

规则：
- 客观事实栏必须自洽，任何人不能在同一时间出现在两个地点
- 角色自述可以是假的，但假话必须有动机且能被线索推翻
- 至少设置 1-2 个「记忆偏差」，制造合理误导（不是撒谎，是记错）

### 5. 线索设计

线索分四类，按比例配比：

| 类型 | 作用 | 建议占比 |
|---|---|---|
| 直接线索 | 指向真相 | 30% |
| 间接线索 | 需要结合推理 | 40% |
| 红鲱鱼（误导） | 指向错误方向 | 20% |
| 氛围线索 | 塑造世界观、情绪 | 10% |

每个重要真相至少要对应 2 条不同类型的线索，避免单点崩塌。

线索卡写法：**只写可被观察到的物理事实**，不写推论。写「地上有一枚 42 码鞋印」，不写「凶手穿 42 码鞋」。

### 6. 幕结构与机制

常见四幕结构：

1. **破冰/建置**：角色介绍、关系建立、动机浮现
2. **第一轮搜证**：发现尸体、初步线索、第一次私聊
3. **第二轮搜证**：新证据、身份反转、核心矛盾激化
4. **投票/还原**：指认凶手 + 完整时间线复盘

可以设计的机制：私聊次数限制、证据卡抢夺、投票权重、隐藏任务、触发式事件。机制要服务于剧情，不要为了复杂而复杂。

### 7. 一致性校验清单

交付前必须逐条核对：

- [ ] 每个角色在凶案时间点的行踪都明确且自洽
- [ ] 凶手是唯一可被推导出来的人
- [ ] 每条关键真相至少有 2 条独立线索支撑
- [ ] 没有线索只能由某一个角色的私密信息单独解释
- [ ] 红鲱鱼有合理解释，不会让玩家觉得被戏耍
- [ ] 所有角色都有动机，没有明显无辜到可以排除的人
- [ ] 凶手玩家的剧本里有足够信息支撑其编造不在场证明

## 输出要求

1. 先给**一页故事梗概 + 人物关系图**，再展开细节
2. 时间线必须用表格，客观事实与角色自述分列
3. 线索卡逐条列出，标注类型和指向的真相
4. 明确指出哪些是给主持人的（凶手是谁），哪些给玩家
5. 交付时附一致性校验清单的逐条结论
