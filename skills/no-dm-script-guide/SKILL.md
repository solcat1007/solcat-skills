# 无需主持的封闭式剧本杀组织指南

## 什么是封闭式本

封闭式剧本杀把主持人的职能**预先写进每个玩家的剧本**：流程按幕推进、线索卡直接印在剧本里、规则由"组织者手册"分发给一名玩家代为宣读。适合凑不到 DM 的车队。

## 开本前分工（组织成败的关键）

| 角色 | 谁来当 | 职责 |
|---|---|---|
| 组织者 | 发起人 | 只负责流程宣读与计时，**正常参与游戏**，不持有额外真相 |
| 计时员 | 可与组织者兼任 | 每幕到点提醒，防止拖场 |
| 记录员 | 自愿者 | 在公共白板/纸上记录公开时间线与已排除项 |

组织者纪律：宣读规则时只念规则原文，不念剧本；自己卡住时和其他人一样按剧本流程走。

## 标准流程时间表（以 4~6 人、3 幕本为例）

| 环节 | 时长 | 做什么 |
|---|---|---|
| 读本 | 20 min | 各自默读第一幕，禁止交流 |
| 自我介绍 | 10 min | 只说公开信息：姓名、身份、与死者/案件的关系 |
| 第一幕搜证 | 20 min | 按剧本线索卡规则轮流传阅/搜证 |
| 集中讨论 | 20 min | 陈述时间线，标记矛盾 |
| 第二幕 | 30 min | 新线索 + 私聊（剧本允许时） |
| 指认投票 | 10 min | 每人 1 分钟陈述 + 投票 |
| 复盘 | 20 min | 逐条宣读剧本中的真相章节，通常按角色顺序 |

## 无主持局的规则自运转设计

1. **流程印在每本剧本最后一页**：全场只需要问"现在到第几环节"，翻页即知
2. **线索卡编号制**：按编号顺序发放/传递，避免有人漏拿关键线索
3. **发言用"轮转制"**：从组织者左手边开始轮流，没人能垄断发言
4. **矛盾公示**：发现时间线冲突必须写到公共记录上，禁止私下藏矛盾
5. **投票前每人必答三问**：你最后见到死者是什么时候？你当时在哪？谁能证明？（这一条能解决 80% 的无主持混乱）

## 常见翻车点与补救

| 翻车 | 补救 |
|---|---|
| 有人读本太慢拖全场 | 读本阶段倒计时，到点强制进入自我介绍 |
| 关键玩家缺席/跳车 | 人数不足时改选更少人数的本；组织者不接替缺席者角色（会破坏信息对称） |
| 线索卡被私藏不公开 | 规则前置：搜到的线索当轮必须公示或声明"我有一张未公开线索" |
| 讨论死循环 | 强制轮转发言，每人每轮限时 1 分钟 |
| 结束后真相没对齐 | 复盘必须逐条念完真相章节再散场，跳过复盘等于白玩 |

## 选本建议

- 新手车队：4~6 人、单案件、无复杂机制的本
- 熟练车队：可尝试带私聊与阵营机制的本
- 人少（2~4 人）：直接选"4 人及以下"或双人本，不要硬拆大本

## 自检清单

- [ ] 组织者人选定了，且知道自己不能比任何人多知道真相？
- [ ] 计时和公共记录有人负责？
- [ ] 线索发放顺序明确？
- [ ] 复盘环节排进时间表了？
