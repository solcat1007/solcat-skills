# Cos 后期 / 漫展场照修图

## 总流程（顺序不要乱）

| 步骤 | 内容 | 关键原则 |
|---|---|---|
| 1. 基础校正 | 镜头校正、水平线、二次构图 | 先裁切再修图，避免白修 |
| 2. 瑕疵清理 | 污点修复画笔（小瑕疵）、修补工具（大块穿帮） | 修补方向顺着结构线 |
| 3. 调色定调 | 曝光/阴影/高光 → 白平衡 → HSL 局部色 | 先光后色；参考环境光源统一色温 |
| 4. 磨皮 | 高低频或中性灰 | 宁可不足不可过度 |
| 5. 液化 | 脸型、身体线条、服装轮廓 | 小笔触，顺骨骼与布料走向 |
| 6. 补妆 | 修容调骨相、重绘眼妆 | 见下文 |
| 7. 细节修复 | 杂毛、瞳色、发色 | 杂毛在高频层修，不要直接涂抹 |
| 8. 特效/合成 | 画光、雷电火焰、溶图 | 最后做，前面全定稿 |

## 磨皮三法怎么选

| 方法 | 做法 | 适用 |
|---|---|---|
| 高低频 | 复制两层：低频高斯模糊管颜色光影，高频"应用图像"分离纹理 | 默认首选 |
| 中性灰 | 50% 灰柔光层 + 黑白观察层，黑白画笔提亮压暗 | 光影瑕疵重（法令纹、泪沟、油光） |
| 双曲线 | 提亮/压暗两组曲线 + 观察层逐笔修 | 商业级精修 |

避坑：

- **不要吸一个颜色满脸涂**——肤色随光影连续变化，必须分区取色
- 保住黑白灰过渡的立体感，避免修成"大平板"/"熨斗脸"
- 分清**卧蚕与眼袋**：卧蚕是表情肌，别磨掉
- 100% 放大检查毛孔纹理是否还在——磨皮过度是新手第一大死因

## 液化要点

- 大腿、腰腹：先液化剪影轮廓，再处理内部阴影（阴影太靠下会显腿粗）
- 服装是布料：顺着褶皱方向液化，不要逆着布纹拉
- 背景直线物（门框、瓷砖缝）是变形照妖镜，推进后必查

## 补妆（妆面翻新）

**修容调骨相**：中性灰或柔光层，加深颧弓下陷、下颌线、鼻侧影；提亮 T 区、颧骨高点、下巴。目标是骨相立体，不是涂白。

**眼妆完整流程**：
1. 眼窝打底：确定眼影范围与边界，边缘羽化 2~3px 揉开
2. 假双/深邃：加深褶线上方渐变，营造眼窝
3. 眼线：钢笔路径描边或笔刷，顺眼型微调
4. 睫毛：素材笔刷逐根补，根部对齐
5. 瞳色/发色：色相饱和度 + 蒙版，保留高光层的白

## 抠图手法速查

| 素材 | 手法 |
|---|---|
| 毛发 | 通道抠图：选对比最强的通道，色阶拉开，画笔涂抹半透明区 |
| 硬边物体 | 钢笔工具，1px 羽化 |
| 纱裙/透明物 | 通道保留透明度，或图层混合模式 |
| 人像整体 | 选择主体 → 选择并遮住 → 输出带净化颜色 |

## 特效、画光与溶图

- **素材融入**：图层模式改滤色/线性减淡 → 色相饱和度对齐主题色 → 模糊匹配景深
- **雷电**：走向要有主次与遮挡关系，主体光源侧亮
- **画光**：曲线工具分层调整，光的方向必须全场一致
- **溶图匹配三件事**：明度、饱和度、色温——逐一对齐后再谈合成感
- **空间感**：近实远虚 + 前景压暗，素材才有"在场"感

## 自检清单

- [ ] 100% 放大检查过毛孔与纹理？
- [ ] 液化后背景直线物没弯？
- [ ] 眼妆边缘羽化了吗，有没有"贴上去"的感觉？
- [ ] 特效光方向与主光源一致？
- [ ] 输出前盖印对比图确认整体没有"越修越脏"？
