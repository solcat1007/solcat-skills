# 剧本杀黑话 / 行话词典

主持、扮演或复盘时使用准确术语，避免向新手解释时露怯。按场景分类。

## 人员角色类

| 术语 | 含义 |
|---|---|
| DM | 游戏的组织者，兼导演、裁判、公证人于一身，一般称主持人 |
| MC | 主持人（另一常见叫法，不是 rapper） |
| NPC | 剧中人扮演的非玩家角色，负责发任务、推动剧情，最常见的 NPC 就是死者 |
| OB | 旁观者（吃瓜群众），行规是必须玩过该本才能旁观 |
| 反串 | 男扮女、女扮男的角色分配 |

## 游戏机制类

| 术语 | 含义 |
|---|---|
| AP | 行动点数，用来收取线索，剧本杀中的"币" |
| BP | 战斗点数，部分剧本中发生战斗时消耗，作用类似 AP，用于限制发动 |
| 互证 | 案发时间段两个及以上人物在一起，可以互相证明没有作案时间 |
| 软逻辑 | 没有实际证据支撑、只靠动机和时间线推定的逻辑链 |
| HE / BE | Happy Ending / Bad Ending，好结局与坏结局 |
| 复盘 | 一局结束后由主持人给玩家梳理整局来龙去脉 |

## 组局类（车文化）

| 术语 | 含义 |
|---|---|
| 开车 | 热心玩家奉献自己担任 DM 带新人，或召集组局 |
| 翻车 | 两种含义：① 凶手被当场识破；② 人没凑够，局没组成 |
| 修仙车 | 熬夜开的剧本杀局 |
| 养生车 | 白天/早上开的剧本杀局 |
| 跳车 | 鸽了已约好的剧本杀局 |

## 使用提示

- 对新手玩家，主持时先用大白话再说术语："消耗一次行动点数（AP）来拿这条线索"。
- 复盘时可以顺势科普 2~3 个术语，提升玩家下一局的体验。
- 开车带新人时，主动解释"开车/翻车/跳车"，避免新人误解为不良词汇。
