# Blender 建模与出图

## 何时使用

- 从参考图/尺寸开始建一个模型
- 已有模型需要清理拓扑、重新布线、减面
- 需要展 UV、做材质、烘焙贴图
- 修改器链（Boolean / Subdivision / Bevel / Solidify / Mirror / Array）的配置与顺序
- 渲染设置（Cycles / EEVEE）、打光方案、出图与批量渲染
- 建模过程中遇到破面、法线错误、Boolean 失败、布尔后布线混乱等问题

## 核心工作流

### 1. 明确目标规格

建模前必须先在回复里固定这几件事，否则后续全部返工：

| 项目 | 为什么重要 |
|---|---|
| 用途（游戏实时 / 影视渲染 / 3D 打印 / 产品图） | 决定面数预算和是否需要封闭流形 |
| 尺寸与单位 | 3D 打印和真实比例场景必须准确，Blender 默认 1 单位为 1m |
| 面数预算 | 实时游戏通常几千到几万面，渲染可上百万 |
| 是否需要 UV 和贴图 | 纯色渲染可跳过 UV，省大量时间 |

如果用户没说，就按最可能的用途假设并在开头声明假设，不要沉默地猜。

### 2. 参考对齐

- 把参考图拖进视口作为 `Image > Reference`，或用 `Shift+A > Image > Reference`
- 在正交视图（`Numpad 1/3/7`）对齐，设 `View > Viewpoint > Front/Right` 保证透视不干扰判断
- 关键尺寸用 `N` 面板的 Dimensions 直接输入数值，不要靠肉眼拖

### 3. 主体建模顺序

推荐的默认顺序（硬表面物体）：

1. **Block out**：用立方体/圆柱堆出体积，只关心大形和比例
2. **Merge**：合并为单网格或保持分件，取决于后续是否需要独立材质
3. **Refine**：进入编辑模式细化结构，`Ctrl+R` 加循环边控制硬度
4. **Subdivision**：需要圆润的地方加 Subdivision Surface，再用 `Ctrl+B` Bevel 或支撑边控制边缘
5. **Cleanup**：删内部面、合并重合点（`M > By Distance`）、重算法线（`Shift+N`）

有机体（角色、生物）则从低模基础网格开始，沿主要形体环线布线，再逐步加密。

### 4. 拓扑原则

- 尽量保持**四边面**，三角面只用于最终不变的硬表面
- 边线要顺应形体的弯曲方向（关节处要有支撑环线）
- 避免极点（5 条以上边交汇的点）放在会形变或高光的区域
- 细分前检查：长条形面、非平面四边形（非平面会导致着色脏）

### 5. UV

- `U > Smart UV Project` 适合快速起步，但接缝不可控
- 需要精确控制时手动标记接缝 `Ctrl+E > Mark Seam`，再 `U > Unwrap`
- 展完用 `UV > Average Island Scale` 统一纹理密度，避免贴图拉伸
- 检查重叠 UV：装 `UV Toolkit` 或用 `Select > Select Overlap`

### 6. 材质与贴图

- 用 Principled BSDF 做基础，重点参数是 Base Color / Roughness / Metallic / Normal
- 需要细节时用 Noise / Voronoi / Musgrave 节点混合
- 烘焙：Cycles 下 `Bake > Diffuse/Combined/Normal`，注意先给物体 UV 且材质里有 Image Texture 节点作为烘焙目标

### 7. 灯光与渲染

| 场景 | 推荐 |
|---|---|
| 产品图/硬表面 | 三点布光：Key + Fill + Rim，Area Light 做主光 |
| 环境写实 | HDRI 环境光 + 一盏定向补光 |
| 快速预览 | EEVEE，开 AO 和 Bloom |
| 最终出图 | Cycles，采样 128-512 起，开 Denoising |

## 常见问题排查

**Boolean 修改器出问题**
- 原因：两物体法线方向不一致、面重合、非流形
- 处理：`Shift+N` 重算法线，把切割体稍微偏移几毫米，确保两者都封闭

**细分后边缘过圆**
- 加支撑边：`Ctrl+B` 或用 `Ctrl+R` 在边缘附近加循环边，距离决定硬度

**法线翻转、表面发黑**
- 编辑模式 `Shift+N` 重算外法线；材质里检查是否误用了背面剔除

**渲染噪点多**
- Cycles 提采样、开 Denoise；EEVEE 则检查是否开了 Soft Shadows 和 TAA 采样

**模型放大后出现锯齿/破面**
- 检查是否是非平面 n-gon，细分前三角化或重新布线

## 常用快捷键速查

| 操作 | 快捷键 |
|---|---|
| 挤出面 | `E` |
| 环切 | `Ctrl+R` |
| 倒角 | `Ctrl+B` |
| 内插面 | `I` |
| 合并点 | `M` |
| 选择循环边 | `Alt+Click` |
| 重算法线 | `Shift+N` |
| 独立显示 | `/`（小键盘） |
| 视角切换 | `Numpad 1/3/7`，`Numpad 5` 切换正交/透视 |

## 输出要求

回答时给出：
1. 明确的建模步骤序列，每步说明用什么工具、改什么参数
2. 涉及数值的地方给出具体数值，不要写"适当调整"
3. 如果有多条路径（如手动布线 vs 修改器），说明各自适用场景
4. 最后列一份检查清单，让用户知道做完了该怎么验证
