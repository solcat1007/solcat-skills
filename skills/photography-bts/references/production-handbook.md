## 二、布光方案详解

### 方案 A：标准三点布光

适合：人像、访谈、产品人物结合

```
        相机
          |
          |
   Key ───┼─── Fill
   45°    |    45°
          |
        Rim（背后侧上方）
```

| 灯位 | 位置 | 附件 | 功率参考 | 作用 |
|---|---|---|---|---|
| Key | 主体前方 45° 侧，高 30-45° | 90cm 柔光箱 或 八角柔光箱 | 200-400W | 塑造主体明暗 |
| Fill | Key 对侧 45°，与主体同高或略低 | 反光板 或 柔光箱 | Key 的 1/4 - 1/8 | 提亮暗部，降低反差 |
| Rim | 主体背后 45°，高于头部 | 标准罩 + 蜂巢 | Key 的 1/2 | 分离主体与背景 |

**关键细节**：Fill 千万别比 Key 亮，否则主体变平，失去立体感。

### 方案 B：蝴蝶光（Butterfly / Paramount）

适合：时尚肖像、女性、强调颧骨线条

- 主光正前方偏上，约 45° 俯角
- 鼻子下方形成对称蝴蝶形阴影
- 辅以正下方反光板补下颌阴影
- 需要柔光，硬光会显毛孔

### 方案 C：伦勃朗光

适合：男性肖像、戏剧感、电影感

- 主光 45° 侧上方
- 暗侧脸颊形成三角形光斑（鼻影与脸颊阴影相接）
- 不补光或轻微补光，保留暗部

### 方案 D：窗光单光源

适合：纪实、自然、采访

- 只用一个窗户做光源
- 主体侧对窗户，距窗 0.5-1.5m
- 反光板放在主体另一侧提亮
- 注意：窗光随时间变化，拍摄要集中在一个时段

### 方案 E：高调 / 低调

**高调（High Key）**：整体明亮，阴影浅，适合商业、母婴、医疗

- 白背景 + 多灯均匀打亮
- 曝光略过 0.3-0.7 档
- 背景灯至少两盏，打匀

**低调（Low Key）**：大面积暗部，局部亮，适合情绪、悬疑

- 黑背景 + 单侧硬光
- 曝光略欠 0.3 档
- 用旗板控制漏光

### 平方反比速查

灯到主体距离变化对亮度的影响：

| 距离变化 | 亮度变化 |
|---|---|
| 1m → 2m | 降到 1/4 |
| 1m → 1.4m | 降到 1/2 |
| 1m → 3m | 降到 1/9 |
| 2m → 2.5m | 降到约 0.64 |

实用推论：**要提亮，先移灯，别急着加功率。**

## 三、光质与附件

| 附件 | 光质 | 适用 |
|---|---|---|
| 标准罩 | 硬，光束窄 | 勾边、打背景 |
| 柔光箱（60-90cm） | 中软 | 人像主光 |
| 八角柔光箱（120cm+） | 很软，圆形眼神光 | 半身像、时尚 |
| 柔光伞（透射） | 软但散，难控 | 快速布光、大场面 |
| 反光伞 | 半硬，有方向 | 主光或补光 |
| 蜂巢（20°/40°） | 硬，控制溢出 | 勾边、打背景、聚光 |
| 束光筒 | 极硬小光斑 | 特殊效果 |
| 旗板/黑旗 | 遮挡 | 控制漏光、加深阴影 |
| 柔光布（蝴蝶布） | 极大面积柔化 | 大场景、多人 |

## 四、分镜表模板

| 镜号 | 景别 | 角度 | 焦段 | 画面内容 | 人物动作 | 光线 | 时长/张数 |
|---|---|---|---|---|---|---|---|
| 01 | 远景 | 平视 | 24mm | 全景建立环境 | 无 | 自然光 | 5s |
| 02 | 中景 | 略仰 | 50mm | 人物入画 | 走入 | 逆光 | 8s |
| 03 | 近景 | 平视 | 85mm | 面部特写 | 转头 | 侧光 | 5s |
| 04 | 特写 | 俯拍 | 100mm | 手部动作 | 操作道具 | 顶部光 | 3s |

**景别定义**：

- 远景：人物占画面 1/4 以下，强调环境
- 全景：人物全身入画
- 中景：腰部以上
- 近景：胸部以上
- 特写：头部或局部细节

**焦段与人像透视**：

| 焦段 | 效果 | 适用 |
|---|---|---|
| 24-35mm | 环境人像，有张力，易变形 | 纪实、环境交代 |
| 50mm | 接近人眼，自然 | 通用 |
| 85mm | 压缩背景，脸部比例最好看 | 标准人像 |
| 135mm+ | 强压缩，背景融化 | 特写、隔离主体 |

## 七、BTS 幕后素材记录规范

### 必须记录的镜头

| 类型 | 内容 | 为什么 |
|---|---|---|
| 灯位全景 | 能看清所有灯的位置、高度、附件 | 后期复现布光的唯一依据 |
| 灯位特写 | 每盏灯的功率、附件细节 | 参数记录 |
| 机位图 | 相机位置与角度 | 复现构图 |
| 现场环境 | 场地全貌 | 交代上下文 |
| 工作过程 | 调整、沟通、试拍 | 幕后故事的核心 |
| 花絮瞬间 | 真实反应、意外、笑场 | 传播力最强 |

### 命名规范

```
YYYYMMDD_项目名_场景_类型_序号
例：20261029_qingtu_studio_lightpos_001.jpg
```

类型代码：

- `lightpos`：灯位
- `bts`：幕后花絮
- `setup`：场景布置
- `final`：成片

### 幕后视频要求

- 每段 15-60 秒，不要单段过长
- 横竖各拍一份（平台适配）
- 收音尽量用外接麦，现场噪音大
- 记录时留出「前 3 秒画面稳定」用于剪辑

### 幕后记录检查清单

- [ ] 每套布光至少一张全景 + 一张特写
- [ ] 文件名符合规范，无中文空格
- [ ] 当天素材当天备份（至少两份，不同介质）
- [ ] 关键灯位参数用文字记录（照片看不清功率旋钮）

## 八、安全事项

**必须单独强调的三件事：**

1. **灯架必须压沙袋**。空灯架重心高，一根线就能带倒，砸到人或设备。室内外都要，风大时加倍。
2. **电缆走线不能过通道**，必须过就用线槽或胶带固定，并设警示。
3. **高空作业**（吊灯、爬梯挂背景布）必须有第二人扶梯，不要单人操作。

其他：

- 灯光发热，柔光布与灯头保持安全距离
- 长时间曝光和高功率灯注意电路负载（常见插座 10A / 2200W 上限）
- 室外拍摄确认天气，雷雨天气不架高灯架
