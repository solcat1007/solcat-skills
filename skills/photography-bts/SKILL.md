# 摄影幕后（BTS）策划与执行

## 何时使用

- 拍摄前：勘景、定调、出布光图和分镜
- 拍摄中：现场机位与灯光调整、幕后素材的记录规范
- 拍摄后：整理幕后花絮、写拍摄手记、复盘

## 核心工作流

### 1. 拍摄前：把模糊需求变成可执行清单

先锁定这五项，缺失任何一项都会在现场出问题：

| 项目 | 需要确定的粒度 |
|---|---|
| 主题与情绪 | 用 3 个形容词 + 1 张参考图定义，不要用"高级感"这类空词 |
| 场景 | 室内/室外、可用面积、层高、窗户朝向与日照时间 |
| 光线条件 | 自然光时段（黄金时刻/蓝调时刻）、是否需要遮光 |
| 人物与服装 | 人数、动作幅度、服装材质（决定布光方式的反射问题） |
| 成片用途 | 横竖屏、打印尺寸、平台压缩，决定构图留白和分辨率 |

### 2. 勘景要点

到现场必须记录：

- **光源方位与时段**：用手机指南针记录窗户朝向，标注一天中光线最佳的时间段
- **电源位置**：数出可用插座数量与位置，判断是否需要延长线和发电机
- **可动空间**：灯架、反光板、走位所需空间，室内拍摄常被低估
- **背景元素**：墙面材质（决定是否需要背景纸）、杂物清理量
- **噪音与人员干扰**：空调、临街、其他使用者

现场拍一组手机照片作为记录，比文字描述可靠得多。

### 3. 布光方案

输出布光方案时建议用俯视示意图 + 参数表，而不是纯文字。

**经典单人与多人布光**

| 方案 | 构成 | 适用 |
|---|---|---|
| 三点布光 | Key（45°侧上方）+ Fill（对侧低位，柔光）+ Rim/Back（背后勾边） | 通用人像，最稳 |
| 蝴蝶光 | 主光正上方偏前，鼻子下形成蝴蝶影 | 时尚、女性肖像 |
| 伦勃朗光 | 主光 45°侧，暗侧脸颊形成三角光斑 | 戏剧感、男性肖像 |
| 窗光单光源 | 只用一个窗户 + 反光板补暗部 | 自然、纪实 |
| 高调/低调 | 提高或压暗整体曝光基调 | 商业白底 / 情绪化 |

**关键参数记录格式**

布光表每盏灯都要写清：位置（方位角+高度）、功率、附件（柔光箱尺寸/格栅/反光伞）、色温、与主体距离。距离是决定光质硬软的核心，不要漏。

平方反比定律：距离加倍，光强降到 1/4。调整亮度优先移灯而不是加功率。

### 4. 分镜

分镜不需要画得好，需要信息完整。每条至少包含：

1. 镜号
2. 景别（远景/全景/中景/近景/特写）
3. 机位高度与角度（平视/俯拍/仰拍）
4. 镜头焦段
5. 人物动作与视线方向
6. 光线状态
7. 预计时长或张数

用表格写最清晰，不要用散文描述。

### 5. 器材清单

按「主机位 / 副机位 / 灯光 / 支撑 / 消耗品」分组，每项标注数量。常见遗漏项：

- 备用电池与存储卡（按拍摄时长 ×2 准备）
- 灰卡/色卡（后期校色必需）
- 大力胶、夹子、沙袋（灯架配重，安全相关）
- 清洁工具（镜头笔、气吹）

### 6. 拍摄日程

按时段排表，每个环节留 15 分钟缓冲。要把「布光调整」和「实际拍摄」分开计时，新手最常见的问题是布光吃掉全部时间。

### 7. 幕后记录规范

BTS 素材本身也是内容，记录时保证：

- 每个关键布光设置有一张「灯位全景图」，能看清所有灯的位置和附件
- 至少一段现场视频，记录调整过程和沟通
- 每张幕后照片标注：日期、场景、镜头焦段、灯位说明
- 统一命名规则，例如 `YYYYMMDD_项目名_场景_序号`

## 输出要求

1. 布光方案用「示意图描述 + 参数表」双轨呈现
2. 所有数值给具体值（距离、功率、色温、焦段），不写"适当"
3. 分镜用表格
4. 现场清单要能直接打印使用，按区域/时段分组
5. 涉及安全的部分（灯架配重、电缆走线、高空）必须单独提示
